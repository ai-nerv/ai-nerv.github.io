Measured against two others

nerv was designed from two existing harnesses: a million-line single binary, and an eight thousand line strictly layered one. Every number here was measured, not read off a README.

Three shapes
pione binaryA ~1M-line Rust coding agent, around seven months old. Everything in one process: the UI, the turn loop, 103 providers, a JavaScript extension runtime. One of the two systems nerv was designed from.
deepseeklayered crates8,390 lines in strict layers — contracts, execution, services, adapters, assembly, apps — with the layering checked on every pull request. Small, disciplined, and does much less.
nervfour processes126,026 lines across four programs that share no code and talk over argv, a pipe and a socket. Each is useful, and testable, with the others absent.

The largest file is the number that decides how a codebase is read. pi's extensions_js.rs is 36,158 lines — nobody holds that in their head, so it is edited by search. nerv's rule is 800 lines, enforced by a gate on the merge path, and all 442 files are under it. deepseek needs no gate: it is small enough that the question has not come up.

What was taken from each

  • From deepseek, the idea that a rule is not a rule until it is a merge barrier. Its architectural invariant is 85 lines of Python running between fmt and clippy. Mechanically it is far weaker than nerv's gate scripts — and it was strictly more valuable, because for a while ours ran only on a laptop. A gate that is not a barrier is a personal ritual.
  • From pi, that a boundary needs a second implementation. A protocol with one implementation is a function call with extra steps: nothing forces the host to say what it means. magi ships a second tool peer in Lua, deliberately unlike the first.
  • From pi, content-hashing what you are about to run. Trust bound to the binary, re-checked before spawn, rather than to a name resolved off $PATH.
  • From deepseek, one spawn site with both a timeout and a kill. Its entire tree spawns a child in exactly one place, and that place has both guards in sixty lines.

Where the others are better

Written down because a comparison that only flatters the thing writing it is an advertisement.

  • pi's deadlines are compiler-enforced. Every command variant carries a deadline, so a caller physically cannot cross its internal boundary without stating one. nerv has a deadline on the memory socket and none in any wire type.
  • pi's compaction is token-aware and never splits a tool call from its result, with a four-rung degradation ladder. nerv keeps a fixed number of entries and measures in characters over four.
  • pi analyses a command before running it. nerv analyses nothing: it decides whether an action is permitted, not whether it is wise.
  • pi's file open is genuinely hardened against the race — canonicalise, open with O_NOFOLLOW, re-stat the descriptor, refuse if it moved. nerv normalises lexically and then reads.
  • pi audits every approval, including the automatic ones. A grant hit here returns quietly, so “what did this session do under standing grants” has no answer.
  • pi crash-tests its durability by hard-exiting the process at named boundaries. nerv's durable write is a buffer flush; nothing calls sync_data.
  • deepseek's whole suite runs without an API key, so its provider path is exercised in CI rather than skipped.
This list is the point of the exercise. It was produced by reading both systems against ours line by line, and several items on it have since been fixed — the gates became a merge barrier, secrets are masked out of the transcript, a chained command no longer passes as its first word. The ones above are the ones still true.

How it was measured

Both systems are checked out and read, in Rust and in their original TypeScript. Counts come from the files git tracks, with generated and vendored trees excluded, and were taken again the day this page was written rather than copied from the analysis they came from.

Where a claim is about behaviour rather than size, it was checked by running the thing: a grant offered a hostile command line, a socket asked in one encoding and answered in another, a harness killed outright to see what survived it.
